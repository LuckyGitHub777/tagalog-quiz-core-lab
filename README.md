# Tagalog Quiz Core — Software Lab

**Explore online:** [Open the public interactive website](https://luckygithub777.github.io/tagalog-quiz-core-lab/). Open the hosted browser experience first; the repository retains source code and optional local usage.

A small JavaScript module with an online interactive demonstration for text normalization, quiz construction, progress tracking, and spaced-review calculations. It is an **educational software-core edition**, not a complete language course or hosted Tagalog Academy.

Use Node.js 22 or a modern browser with ES modules. Run the small fictional-data smoke test with `node --test tests/test_core.mjs`. The implementation is at [assets/js/core.js](assets/js/core.js). The included examples use generic two-item practice data; no learner records, lesson catalog, printable content, licensed third-party media, or hosted services are included.

Text normalization and quiz construction are software behavior, **not evidence of teaching effectiveness or linguistic accuracy**. Review actual teaching content with qualified language educators before publication or use.
